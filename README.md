# shotcut-video-skill
Claude-Skill für automatisierten Videoschnitt: aus Transkript und leerer Shotcut-Projektdatei erstellt Claude einen begründeten Schnittvorschlag und direkt die fertige, geschnittene .mlt-Projektdatei (Lang-/Kurzversion, Trailer). Inkl. Fix für einen bekannten Shotcut/MLT-Kompatibilitätsbug.
